------------------------
Propellant Data Configs.
------------------------
BEGIN INSTRUCTIONS
1) Read the variable descriptions below. They are material properties:
	type:		<"OXIDIZER", "FUEL">,			~
	cost:		cost per unit mass,			USD/kg
	mlr_wgt:	molar weight,				kg/mol
	rho: 		density, 				kg/m^3
	cp: 		specific heat at constant pressure, 	J/(kg-K)
	k:		thermal conductivity, 			W/(m-K)
	mu:		dynamic viscosity,			Pa-s

2) To add a new material config., copy the format below. If the property varies (most do), set the value
	to "varies". This is more of a bookkeeping value because some propellants have functions
	coded from correlations to solve for their thermodynamic properties based on state values. If
	you don't want to go to the trouble of coding a correlation for a propellant, you can put a set
	value for that property.

\EXAMPLE\
type = <value, "varies">
cost = <value, "varies">
mlr_wgt = <value, "varies">
rho = <value, "varies">
cp = <value, "varies">
k = <value, "varies">
mu = <value, "varies">
\end\

3) Separate material configs. as shown below

\propellant_1\
<properties>
\end\

\propellant_2\
<properties>
\end\

END INSTRUCTIONS
